# IELTS Pro Institute Homepage

A modern, interactive, and highly animated homepage for the **IELTS Pro Institute**. Built with **React**, **Bootstrap**, and **CSS animations**, this project features smooth scrolling, animated sections, interactive buttons, gradient texts, floating bubbles, and a visually appealing layout.

## Features

- Fully responsive **navbar** with hover and toggle animations.
- **Hero section** with:
  - Gradient animated text
  - Floating hero image
  - Animated call-to-action button
  - Background particles (optional)
- **Features section** with:
  - Interactive feature cards with gradient hover effects
  - Bounce animation for icons
  - Scroll-reveal animations
- **Testimonials section** with animated cards and glowing text.
- **Footer section** with popup and fade-in animations.
- **Floating bubbles** effect on page background for enhanced visuals.
- Smooth **scrolling behavior**.
- Fully customizable gradient animations for texts and cards.

---

## Technologies Used

- **React** – For component-based UI
- **Bootstrap 5** – Responsive layout and utilities
- **CSS3** – Animations, gradients, shadows, and hover effects
- **AOS** – Scroll-based animation library
- Optional: **tsparticles** – Background particle animation
- **JavaScript** – For dynamic elements and effects
